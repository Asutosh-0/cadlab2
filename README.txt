CADLAB PREMIUM WEBSITE
======================

Pages:
- index.html — Home
- about.html — About Us
- services.html — Services
- products.html — Products / platform overview
- training.html — Training & Skill Development
- saas.html — SaaS / WebGIS
- daas.html — Drone as a Service
- projects.html — Projects portfolio
- contact.html — Contact & inquiry

HOW TO PREVIEW
1. Extract this ZIP.
2. Open index.html in a browser. For best local testing, use VS Code + Live Server.
3. Upload the complete folder to your static host (Cloudflare Pages, GitHub Pages, etc.).
4. Keep the assets folder and all HTML files together.

CUSTOMISATION
- Logo and supplied images are in assets/.
- Shared styling is assets/css/style.css.
- Shared interactions are assets/js/main.js.
- Contact form submits enquiries online to programerasu@gmail.com using FormSubmit AJAX. On first deployment, FormSubmit sends a one-time activation email to that inbox; open it and confirm the activation before live enquiries can be delivered. This static form service does not store submissions in your own database.
- Projects page uses clearly labelled placeholder tiles; replace with approved project case studies and images.
- Products page is an overview because the supplied blueprint does not specify product names or a detailed product catalogue.

SOURCE CONTENT
Company details and service descriptions are based on the supplied six-page CadlaB website blueprint. Phone, email and address are taken from that blueprint.


ENQUIRY FORM SETUP
1. Publish the website.
2. Submit one test enquiry from the Contact page.
3. Open programerasu@gmail.com and confirm the activation email from FormSubmit.
4. Submit another test enquiry and confirm it arrives.
5. If delivery is not activated, the form displays a fallback email instruction.

BOOTSTRAP
Bootstrap 5.3.3 CSS and JS are loaded from jsDelivr CDN. Internet access is required for Bootstrap assets.
